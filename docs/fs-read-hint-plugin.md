# dsh-fs-read-hint 已从 build374 随包插件中移除

该临时插件从 build300 起随包发布，在 DSH 拒绝修改未读文件时附上本会话读过的同名文件路径。build374 恢复显示 DSH 自己的报错。修改现有文件前仍需先读目标文件。

从 build373 升级时，只有文件集合、摘要、权限及运行时依赖链接与旧受管树相符，且该树匹配原运行时健康回执，才会移入运行时回退记录。Web 注册清除能归属于旧随包路径的依赖及链接。同名第三方插件及自定义目录保留。
