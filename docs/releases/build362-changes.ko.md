# DSHA 0.2.1-rc.5-20261113.1000-dsh0.2.2-rc.1 / build362

- 엔지니어링 기반 빌드(새 사용자 인터페이스 없음): build362는 build361 이후 Kotlin 툴체인 배치, Rust 측면 경로 R0, A2 저장소/파일 slice1+2, 그리고 A7 / R1 설계 문서와 build361 실기기 수용 영수증을 반영합니다. **Kotlin과 Rust 두 배치는 빌드/포맷/네이티브 측면 경로 기반이며 사용자 가시 기능을 바꾸지 않습니다**; A2는 기능 계층/장부 교체이고 새 사용자 인터페이스도 추가하지 않습니다.
- Kotlin 툴체인(엔지니어링): AGP 9.1.1 built-in Kotlin, KGP 2.2.10 고정(`org.jetbrains.kotlin.android` 미적용), jvmTarget 17; ktfmt 0.64 `--kotlinlang-style`을 포맷 게이트와 CI에 포함(`tools/format-kotlin-tree.py --check`); `util/ShellQuote`를 파일 전체 단위로 Kotlin으로 이전했으며 동작은 동등하고 Java 호출 형태는 그대로입니다. 사용자 가시 동작은 바뀌지 않습니다.
- Rust 측면 경로 R0(엔지니어링, 패키지 미포함): `rust/` crate, 16개 crate의 오프라인 vendor(782개 파일 / 7,384,177 B)와 툴체인 잠금을 추가했습니다. `tools/rust/build.py`가 빌드와 바이트 재현을 담당하고 ELF / 경계 / APK 게이트와 CI 4모드(check / repro / native / differential)를 갖췄습니다. **R0는 APK 패키징에 연결되지 않으며 `.so`도 패키지에 포함되지 않습니다**; APK에는 동봉 라이선스 전문만 추가됩니다(34개 파일 / 170,896 B, 약 171 KB, 비압축 텍스트 기준). 사용자 가시 동작은 바뀌지 않습니다.
- 저장소/파일 A2 slice1+2(기능 계층, 새 UI 없음): SAF 권한 장부를 독립 장부로 전환하고 이전 `saf_grants`를 읽기 전용으로 이전하며 `SafGrants`가 장부를 사용합니다. 철회·세대·한도 의미는 장부가 담당하고 A1 출구에서 넘긴 세 개의 P2도 함께 수정했습니다. `/app/saf/*` 엔드포인트와 `BRIDGE_PROTOCOL=3`은 그대로이며 워크벤치 UI는 여전히 slice3 담당입니다.
- 덮어쓰기 업그레이드 영향: A2는 `runtime-descriptor`의 `launcherInputs` 안에 있는 `saf/`를 변경하므로 `runtimeId`가 갱신됩니다. **361→362 덮어쓰기 후 첫 실행은 관리 런타임 유지보수 페이지로 한 번 진입**해 관리 런타임 시험 실행을 수행하며, 이는 예상된 동작이고 개인 데이터는 보존됩니다. runtimeId는 A2 병합 후 `prepare-runtime-descriptor.py --check` 실측값을 따릅니다(릴리스 준비 시에는 자리 표시자를 두고 최종 head에서 기입). fixed-inputs는 고정된 `fixed-inputs-20261105e`를 유지하며 내장 `dsh-web-mobile` 3.3.5와 기본 활성화도 그대로입니다.
