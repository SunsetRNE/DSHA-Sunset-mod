## Планшеты, длинные диалоги и потоковые ответы

- Совместимость SSE: корректная обработка блоков событий без data. Сохранена совместимость SDK с завершённым JSON при EOF; повреждённый JSON по-прежнему вызывает явную ошибку.
- В длинных диалогах сокращены повторные преобразования и создание компонентов. Статусы сеансов обновляются постепенно; порядок ветвей рабочего пространства сохранён без глубокой рекурсии.
- Планшетный интерфейс реже сканирует всю страницу. Высокая частота обновления и выбор темы повторно используют неизменные входные данные, сохраняя проверки фокуса, дисплея, настроек и поколения страницы.
- При запуске сокращены повторные чтения APK; необязательные модули Python загружаются по необходимости. Границы разрешений, данных и ошибок сохранены.
- Основная и независимая аварийная среды используют одинаковые байты архива для сохранения размера APK; рабочие каталоги и жизненные циклы независимы.
- Проверки хоста, браузера и устройства описываются отдельно в отчёте поставки. Фиксированное ускорение и все исторические варианты данных не гарантируются.
