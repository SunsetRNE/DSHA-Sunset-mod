# DSHA 0.2.2-rc.5-20261122.1650-dsh0.2.2-rc.5 / build375

- L’application et DSH intégré utilisent la version 0.2.2-rc.5. Sur les appareils arm64 sous Android 11 ou ultérieur, `dsh.android.client` conserve la signature E7E3 pour la mise à jour.
- Quand vous modifiez les réglages de l’espace de travail ou restaurez une sélection, seuls les éléments modifiés sont enregistrés. Les autres conservent leurs valeurs ou continuent d’hériter des valeurs par défaut. Dans le groupe de modèles des sous-agents, modifier uniquement l’état d’activation ou la liste des modèles enregistre ce seul changement, et l’autre réglage continue de suivre l’évolution de sa valeur par défaut s’il en héritait déjà. Pour un fournisseur personnalisé, lorsque seul le nombre de nouvelles tentatives est défini dans les réglages de relance, le mode de relance continue de suivre sa valeur par défaut si vous changez seulement le nom d’affichage.
- Après un retour au premier plan ou une mise à jour, DSHA vérifie de nouveau l’espace de travail précédent pour éviter qu’une instance déjà arrêtée bloque le démarrage. Si vous ouvrez l’accueil après une mise à jour pendant le nettoyage des anciennes copies, DSHA attend de pouvoir poursuivre la mise à jour de l’environnement d’exécution. Cela évite de signaler à tort un échec du contrôle de disponibilité.
- Le journal de démarrage indique où se termine la mesure du démarrage. Les messages enregistrés une fois l’espace de travail Web prêt affichent le temps d’exécution et sont comptés séparément.
- Si vous avez choisi d’ouvrir l’espace de travail web au démarrage, toucher l’icône sur l’écran d’accueil ouvre aussi cet espace lorsque l’accueil de l’application est en arrière-plan. L’application reste sur son écran natif si l’environnement nécessite une maintenance ou si l’espace de travail précédent doit être vérifié.
- Dans une instance clonée de l’application, l’enregistrement d’une copie est confirmé une fois l’écriture terminée. Après avoir désactivé ADB depuis l’écran d’association du débogage sans fil, l’interrupteur du canal d’exécution de l’appareil s’affiche comme désactivé au retour. Lorsqu’une vérification ADB en arrière-plan se termine, expire ou est interrompue, l’application arrête les processus de cette vérification et conserve l’association sans fil existante.
- Les préréglages de l’écran virtuel affichent la description et les choix disponibles. Annuler conserve le choix actuel. Si le service d’accessibilité de DSHA n’est pas connecté lors de l’ouverture des nœuds de l’écran virtuel, l’application signale que le service est indisponible.
- Supprimer un fournisseur de modèles retire sa configuration du profil actuel et conserve la clé API partagée. Pour supprimer les deux, effacez d’abord la clé sur la page de modification du fournisseur et enregistrez, puis supprimez le fournisseur. Si une modification de la configuration est rejetée, la clé est conservée.
- Le changement d’une langue synchronisée avec l’application actualise l’espace de travail web sur place. Quand l’espace de travail est ouvert, vous retrouvez la même page web en revenant après un changement de thème clair ou sombre. Le réglage de l’affichage pour ordinateur s’applique à la création d’une nouvelle vue web. Le texte et les boutons d’un rapport d’erreur déjà ouvert sont aussi actualisés. L’action qui affiche la cause et les options de réparation ouvre l’écran de récupération. Le retour ramène à l’accueil de l’application.
- Une sauvegarde des paramètres seuls regroupe les paramètres natifs transférables, la configuration des modèles, les profils et les préréglages. Les paquets d’installation des extensions et les archives en double sont exclus de ce périmètre. Les anciens paramètres pris en charge et les déclarations de profil écrites par l’utilisateur sont conservés. Une option distincte contrôle le champ de clé API de l’application. La sauvegarde complète et les anciennes archives conservées gardent leurs propres parcours de restauration.
- Les statistiques de stockage signalent les catégories lues partiellement et affichent les tailles déjà mesurées. Une taille illisible est indiquée comme inconnue. Une catégorie dont l’absence de contenu a été vérifiée affiche 0 B.
- La fiche d’une compétence montre d’abord un aperçu. Le code source complet se lit page par page. La fiche reste visible pendant le déplacement vers les éléments récemment supprimés ou la restauration. Les commandes redeviennent disponibles à la fin.
