# DSHA 0.2.2-rc.5-20261119.1852-dsh0.2.2-rc.5 / build373

- 應用程式與內建 DSH 均為 0.2.2-rc.5。Android 11 及以上的 arm64 裝置可使用原有 E7E3 簽章更新 `dsh.android.client`。
- 儲存空間統計和清理會顯示進度列、目前階段和已處理數量。掃描期間可以看到數字持續更新。
- 在「儲存與檔案」中展開執行階段的回復副本，可查看各份副本的大小和保留原因。
- 從首頁開啟外掛程式頁面時，可以先查看現有清單。點選偵測按鈕會重新檢查，並顯示驗證狀態。
- 手動清理可壓縮交易紀錄和檔案內容皆已核對的較舊 DSH 副本。可在明細中將它解壓縮回原位置，原有的執行階段回復資格維持不變。
