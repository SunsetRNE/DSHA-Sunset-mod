# DSHA 0.2.1-rc.5-20261119.0400-dsh0.2.2-rc.5 / build370

- Код версии повышен до 370. Локальная сборка Standard сохраняет имя пакета DSHA `dsh.android.client` и прежний сертификат подписи E7E3. Поддерживаются устройства arm64 с Android 11 и новее.
- Встроенный DSH обновлён до 0.2.2-rc.5, а мобильный интерфейс dsh-web-mobile — до 3.3.5. Включены обновления запуска, обслуживания среды, управления плагинами, терминальных сеансов и автоматического резервного копирования.
- Для доступа к файлам других приложений используется системное окно выбора файлов. Улучшена обработка сужения и отзыва прав на каталоги при ошибке сохранения разрешения.
- При обновлении поверх build308 с тем же пакетом и сертификатом при первом запуске может потребоваться обслуживание среды. Приложение проверит существующую среду и при необходимости предложит её обновить.
