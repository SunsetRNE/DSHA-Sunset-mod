# DSHA 0.2.2-rc.5-20261119.1852-dsh0.2.2-rc.5 / build373

- 앱과 내장 DSH의 버전은 모두 0.2.2-rc.5입니다. Android 11 이상 arm64 기기에서 기존 E7E3 서명으로 `dsh.android.client`를 업데이트할 수 있습니다.
- 저장 공간을 검사하거나 정리할 때 진행 표시줄, 현재 단계, 처리한 항목 수를 볼 수 있습니다. 검사 중에도 수치가 갱신됩니다.
- 저장소 및 파일에서 런타임 복원 사본을 열면 각 사본이 차지하는 공간과 보관 이유를 확인할 수 있습니다.
- 홈의 플러그인 화면에서는 검사 중에도 기존 목록을 볼 수 있습니다. 감지 버튼을 누르면 새로 검사하고 검증 상태를 표시합니다.
- 수동 정리에서는 트랜잭션 기록과 파일 내용을 검증한 이전 DSH 사본을 압축할 수 있습니다. 상세 화면에서 원래 위치에 다시 풀 수 있습니다. 해당 런타임으로 되돌릴 수 있는 조건은 그대로입니다.
