## 动态画面点按

原始坐标动作以前会因为动画改变像素、或虚拟屏采样已前进一帧而被拒绝；连续动画还会使已经编码完成的预览反复丢弃。本版新增 **设备授权 → 屏幕确认 → 动态画面点按**，可选择已安装应用或填写完整包名，保存后按应用开启；默认名单为空，清空后恢复严格校验，不预置附件所列游戏名单。

开启的应用使用按单调时钟计量的 **5 秒观察窗口**，从实际截图请求/源图复制开始计时，编码、确认和排队不续期，与 30/60/90/120fps 无关。只放宽对应坐标动作的动态像素条件；实际目标、运行代次、尺寸、旋转、遮挡、屏幕确认、最新配置与单次观察仍校验，type/key/check、语义节点和 anchored-click 的原规则保留。

虚拟屏返回真实源帧，另列当前帧，不把旧像素改标成新图；旧源图不能通过较大的 currentFrameSeq 覆盖已采用的新源图。Manager 仅信任本机设置，覆盖调用方伪造字段；Core 拒绝旧修订和同号异名单。排队与 socket 握手后、首个业务字节发送前再检查配置撤销，已经发送的 UNKNOWN 不重放。

边界：本机保存与独立 Core 不是原子分布式事务，撤销前已发出的动作仍可能先于新修订抵达而执行；不承诺撤回已发送动作。动态页面本身可在 5 秒内变化，本功能不承诺内容识别或交易保护。设置不会通过普通备份/portable 配置导入。

## 原生页面与网页高刷新率

应用级 `UiFrameRate` 统一管理所有 Activity，覆盖原生主页、设置、终端和保留的 WebView。前台已附着、非 PiP 窗口从自身显示器选择同分辨率、系统峰值允许且不超过 120Hz 的刷新率；API35 同步设置 decor 与真实 WebView 的数值请求。监听省电、显示器、峰值设置、窗口附着和前后台变化，暂停、销毁或分离时释放请求；旧宿主不会清掉新宿主持有的 WebView 请求。

未附着/无效显示器返回系统默认，不调用会抛错的 Activity display 兜底；不改系统设置、不强制显示模式/分辨率、不用持续动画或忙循环制造高刷。宿主测试证明请求和释放正确，实际 OEM 仲裁、屏幕 90/120Hz、WebView 绘制帧率、触控延迟和耗电仍待真机验收。

## 文件管理器

- 原生/系统文档入口：目录由 `DirectoryStream` 流式枚举并写入私有 SQLite 元数据快照，页缓存 256KiB、最多 4 个活动快照，保持完整可访问列表与随机分页；异常、取消、关闭均释放本次资源。搜索保留原有结果/扫描上限。ASCII 名称仍忽略大小写排序，非 ASCII 大小写排序可能与旧 Java 比较器不同。
- 取消：自有同进程查询传播取消范围，不在主线程等待远端取消。系统/MT 跨进程 child/search 查询仍受 Android final API 限制，不能声称它们的取消完全贯穿。强杀进程可能留下私有快照缓存，本轮未新增扫描用户目录的清理行为。
- 文件打开：先以非阻塞、禁止最终链接跟随的 FD 打开并 fstat 验证普通文件，持有该 FD 后建立带关闭监听的最终描述符；原路径、私有范围和实际对象校验成功后才允许截断。阻止文件在检查后被换成 FIFO 时卡死，保持客户端关闭释放租约。
- 网页目录：变更通知先筛选目标并最多保留一次待处理失效事件；列表和文本预览的 rejected promise 进入现有错误状态，旧路径/已取消结果不覆盖新页面，可再次重试。
- 本地目录首屏：通过显式可选接口流式取前缀，保留已有 2000 条 UI 上限及截断提示，最多保存 2001 个候选名；只 stat 选中的条目。原两参数完整 API 不改，未知/远端/自定义提供方保持自己的完整 API。Linux 同排序权重名称以原 scandir UTF-8 顺序消除差异。
- 本地监视：目录一个 native watch；文件/暂不存在文件监视规范父目录与名称，避免 chokidar 为一个文件预扫描整个目录。删除/重建/原子替换和取消均覆盖；Node 原生监听器在 error 后不一定发 close，异常终止显式完成退出信号，保持真实错误而不无限等待。父目录被删再重建自动恢复仍为上游边界。
- 图片保存：使用响应 Blob 并绑定页面取消与释放，移除整张图片的额外 JS 分块数组及重组副本。33MiB 真实载荷验证字节相同；没有把它说成手机 5GB 传输验收。

上述六个固定补丁已纳入 registry、真实运行时归档、安装链和精确 APK 验证。普通写入/编辑空 `justification` 的已有兼容修复继续保留，本轮 62 项宿主回归通过，不放宽破坏性操作或显式提权守卫。
