# DSHA 0.2.1-rc.5-20261103.1300-dsh0.2.1-rc.5 / build294

## Изменения из upstream build279–294

- Экспериментально: страница виртуального экрана переделана под четыре состояния (выключен, создаётся, работает, ждёт очистки), в альбомной ориентации — раскладка в две колонки; после поворота снова открывается исходное приложение, вернулся плавающий предпросмотр.
- Экспериментально: страница восстановления запуска объясняет причины сбоев и дальнейшие действия; нативный экран загрузки и панель ошибок чата дополнены средствами ожидания, диагностики и восстановления. При повторном открытии приложения после разблокировки фоновые проверки ADB уступают приоритет. Это попытка устранения проблемы: исходное зависание воспроизвести не удалось.
- Экспериментально: фоновая проверка плагинов выполняется только при открытой странице плагинов. Прямой вход в Web и возврат через уведомления или список последних приложений сохраняют выбранную цель запуска; её также можно изменить в настройках Web.
- Если порт моста устройства не опубликован или не читается, запрос завершается ошибкой, без перехода на порт 3090 и передачи учётных данных этой установки. Экспериментальный `/app/install` передаёт APK из контейнера системному установщику; подтверждение пользователя по-прежнему обязательно, а в фоне окно открывается через уведомление.
- Экспериментально: диагностика сети сообщает об ограничениях доступа, проблемах служб и DNS, признаках замораживания процессов. Автоматическое исправление не выполняется.
- Резервное копирование в одно нажатие сначала останавливает запись, затем проверяет расположение данных, исключая локальные файлы состояния устройства. Подмена пользовательских данных по-прежнему прерывает копирование.
- Экспериментальные окна справки адаптируются к форме окна. Анимация этапов учитывает системные настройки; пункт поддерживаемых устройств на странице «острова» не перекрывается нижней капсулой; область прокрутки журнала запуска не меняется до конца жеста.

## Локальные изменения запуска и главной страницы

- Сокращены повторные проверки и чтение с диска при запуске; проверка целостности среды и обработка ошибок сохранены.
- Событие готовности службы сразу обновляет главную страницу и продолжает переход в Web, не дожидаясь следующего периодического обновления. Проверки готовности не пропускаются.
- На главной странице «Перезапустить» теперь слева, а «Остановить» справа, как в широкой, так и в узкой раскладке. Для языков с письмом справа налево сохраняется системное направление интерфейса.
- Сохранены исправления высокой частоты обновления, нажатий на движущийся экран и файлового менеджера среды. Оптимизация размера APK сохранена: обычная и аварийная среды используют общие байты архива в пакете только при совпадении контрольных сумм; рабочие каталоги остаются независимыми.
