# DSHA 0.2.2-rc.5-20261122.1650-dsh0.2.2-rc.5 / build375

- 앱과 내장 DSH의 버전은 모두 0.2.2-rc.5입니다. Android 11 이상 arm64 기기에서 기존 E7E3 서명으로 `dsh.android.client`를 업데이트할 수 있습니다.
- 작업 공간 설정을 수정하거나 선택한 설정을 복원하면 실제로 바뀐 항목만 저장합니다. 다른 설정은 기존 값이나 상속 상태를 유지합니다. 하위 에이전트의 모델 풀에서 사용 여부와 모델 목록 중 하나만 바꾸면 그 항목만 저장되며, 다른 항목이 기본값을 상속하고 있었다면 이후 기본값이 바뀔 때도 그대로 반영됩니다. 사용자 지정 공급자의 재시도 설정에서 횟수만 지정했다면, 표시 이름만 변경해도 재시도 모드는 계속 기본값을 따릅니다.
- 백그라운드에서 돌아오거나 앱을 업데이트한 뒤 이전 작업 공간을 다시 확인해 종료된 인스턴스가 시작을 막지 않도록 합니다. 업데이트 후 이전 복사본을 정리하는 동안 홈을 열면, 실행 환경을 계속 업데이트할 수 있을 때까지 기다려 환경 검사 실패가 잘못 표시되는 문제를 방지합니다.
- 시작 로그에 시작 시간 측정이 끝나는 지점을 표시합니다. 웹 작업 공간이 준비된 뒤의 로그에는 실행 시간을 표시하고 시작 단계와 별도로 집계합니다.
- 시작 위치를 웹 작업 공간으로 설정했다면 앱 홈이 백그라운드에 남아 있을 때 기기의 홈 화면에서 앱 아이콘을 눌러도 웹 작업 공간이 열립니다. 환경 유지 관리나 이전 작업 공간 확인이 필요하면 앱 화면에 머뭅니다.
- 복제 앱에서 파일의 복사본을 저장하면 쓰기가 끝난 뒤 성공 메시지가 표시됩니다. 무선 디버깅 페어링 화면에서 ADB를 끄고 기기 실행 채널로 돌아가면 스위치가 꺼진 상태로 표시됩니다. 백그라운드 ADB 연결 확인이 끝나거나 시간 초과 또는 중단되면 해당 확인의 프로세스를 정리하고 기존 무선 페어링을 유지합니다.
- 가상 화면 사전 설정에 설명과 선택 가능한 항목이 함께 표시됩니다. 취소하면 현재 선택이 유지됩니다. 가상 화면 노드를 열 때 DSHA 접근성 서비스가 연결되어 있지 않으면 서비스가 사용 불가 상태임을 안내합니다.
- 모델 설정에서 공급자를 삭제하면 현재 프로필의 공급자 설정이 제거되고 공유 API 키는 유지됩니다. 공급자와 키를 모두 삭제하려면 먼저 해당 공급자의 편집 화면에서 키를 지우고 저장한 뒤 공급자를 삭제하세요. 설정 변경이 거부되면 원래 키가 유지됩니다.
- 앱과 동기화되는 언어로 전환하면 현재 웹 작업 공간에서 화면이 갱신됩니다. 웹 작업 공간을 열어 둔 상태에서 밝은 테마와 어두운 테마를 전환하고 돌아오면 기존 페이지가 그대로 표시됩니다. 데스크톱 레이아웃 설정은 새 웹 보기를 만들 때 적용됩니다. 열려 있는 오류 보고서의 본문과 버튼도 바뀝니다. 원인 및 복구 옵션을 보는 동작은 복구 화면을 열며, 돌아오면 앱 홈으로 이동합니다.
- 설정만 백업하면 옮길 수 있는 앱 설정, 모델 구성, 프로필, 사전 설정이 포함됩니다. 플러그인 설치 패키지와 중복 압축 파일은 이 백업 범위에서 제외됩니다. 지원되는 이전 설정과 사용자가 프로필에 작성한 구성은 유지됩니다. 앱의 API 키 필드는 별도 옵션으로 선택합니다. 전체 앱 백업과 기존 보관 파일은 각각의 복원 경로를 사용합니다.
- 저장 공간 통계에는 일부만 읽은 분류가 표시되며, 이미 확인한 용량이 표시됩니다. 읽지 못한 용량은 알 수 없음으로, 비어 있음이 확인된 분류는 0 B로 표시됩니다.
- 스킬 상세 화면에 미리보기가 먼저 표시되며, 전체 소스를 열면 페이지별로 읽을 수 있습니다. 최근 삭제 항목으로 이동하거나 복원하는 동안 상세 화면이 유지되며, 작업이 끝난 뒤 다시 조작할 수 있습니다.
