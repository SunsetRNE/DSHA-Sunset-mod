## DSH 归档

## 失败与复验

打包测试初轮遇到三个合成 npm 树缺少新增网页图标，覆盖生产代码拒绝缺少输入的路径。补齐带有独立摘要的测试图标后，第二轮剩一个旧顺序断言，显示生成的文件顺序已变化。将断言改成新的真实文件次序，并保留 Windows/POSIX 的同名及大小写检查。第三轮七个打包测试全部通过。另有 20 个受管 APK 资源测试全过。[打包初轮](dsh-packaging-r1.log) · [第二轮](dsh-packaging-r2.log) · [第三轮](dsh-packaging-r3.log) · [受管资源](managed-assets-r1.log) · [测试源码](../../../../tools/test-dsh-runtime-packaging.py)
