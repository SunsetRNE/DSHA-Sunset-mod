# 377 正式资源下的原生备份测试

Windows 全套的五个 NativeDataChoicesTest 方法均在同一处失败。测试刚调用 Dialog.show 就同步点按正按钮，Robolectric 主线程使用 PAUSED 模式，注册自定义按钮的 OnShowListener 仍在队列里。共同结果是测试提前点击、备份密码仍为 null，五种后续情境都未到达。修订 NativeDataChoicesTest.openExportDialog，让主线程先派发已经排队的对话框显示事件。全部原断言保留，另检查空密码字段与两次输入不一致时的字段确有错误提示。保留以 Shadow.extract 访问 ShadowActivity 的做法。
