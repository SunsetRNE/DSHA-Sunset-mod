# build377 可移机密码备份宿主验收

build376 人工备份把聊天和附件放入未加密的 `DSHADATA`。假如用户把秘密直接写进聊天，关掉“包含原生 API Key”也会带出正文。用同一份合成聊天及 48 MiB 附件实测，标准 tar/gzip 展开后，两种标记在 build376 的载荷内都可直接检索，build377 的默认路径为零处。两种包用本次相同的合成资料，实际载荷内容用 SHA-256 核对。

## 改了哪里

以下源码均位于 `F:/DSHA_RESTART/source/build377-local/app/src/main/java/com/deepseekharness/app/`。完整相对路径与本次文件字节摘要列于 [source-inputs.json](source-inputs.json)。

复用既有 v5 和 Bouncy Castle 1.85.2。新包使用 600000 次 PBKDF2-HMAC-SHA256、随机盐、随机 nonce 与 AES-256-GCM。备份密码只在输入控件、进程内 ViewModel 与工作线程副本间移交。SAF 取消、启动失败、任务完成或 ViewModel 清理时释放并清理可清理的数组。进程重建后的选文件回调要求重新发起。旧版无交互兼容方法仍供已有测试或内部调用，源码检查未发现当前正式页面通过这些 API 暗中启动普通明文备份。
