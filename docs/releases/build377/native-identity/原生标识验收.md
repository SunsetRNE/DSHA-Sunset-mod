## 重放

在 PowerShell 执行。最后一个参数改为新文件路径即可保留每轮结果。加 `--after <签名成品APK>` 可对生产 APK 执行相同的资源表与像素检查。

```powershell
$brandSource='F:/DSHA_RESTART/source/build377-local'
$brandEvidence='F:/DSHA_RESTART/artifacts/build377-local/native-identity'
$baseline='F:/DSHA_RESTART/artifacts/build376-formal-20261125/signed/dsha-0.2.2-rc.5.apk'
python -B "$brandEvidence/verify_brand.py" --source $brandSource --before $baseline --sdk F:/DSHA_RESTART/toolchains/current/android-sdk --output "$brandEvidence/replay.json"
python -B "$brandSource/tools/test-release-identity.py" -v
```

旧版门禁要求新旧像素完全相同，适用于 build376 的无损转码。此轮检查改为“新成品等于项目几何源码输出”，另保留旧图名单、旧尺寸和逐图比较。第一次盘点的 PowerShell 通配符路径未展开，按实际目录重新查询后已核对。软件包中的模型、第三方许可和致谢由各自的发布检查核验。
