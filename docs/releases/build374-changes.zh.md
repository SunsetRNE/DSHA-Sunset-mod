# DSHA 0.2.2-rc.5-20261119.2300-dsh0.2.2-rc.5 / build374

- 应用与内置 DSH 均为 0.2.2-rc.5。Android 11 及以上的 arm64 设备可用原 E7E3 签名覆盖升级 `dsh.android.client`。
- 改善经典 proot 下的启动和插件读取，修复在主页检查全部插件更新时可能退回桌面的问题。修复打开插件安装链接或关闭插件安全模式时可能闪退的问题。修复插件卡片已显示新版，点击更新时却误报环境变化的问题。
- 调整加载窗口的文字对齐，移除“待核验”标签。网页插件页仅列出用户可管理的插件，Android 壳集成仍由应用提供。修复网页插件更新失败后旧版本可能无法继续使用的问题。移除旧的内置读取提示插件。
- 设置中的常亮和省电选项支持整行点击，也改善了移动网页切换面板时的动画反馈。
- 插件列表自动刷新后，仍可在检查更新按钮旁查看最近一次手动检查的结果。
- “跟随系统”和手动指定的语言相同时，重新打开语言选择框也会勾选刚保存的选项。
- 平板打开设置时，安装页会先显示。环境状态和版本在后台读取，读完后自动填入。
- 修复运行时尚未安装时进入有限模式会闪退的问题。缺少健康检查记录时，维护页也能继续核验环境。修复没有待迁移的旧资料时，安全启动或快速停止后下次普通启动可能被拦截的问题。恢复页会说明已知原因，并提供查看详情的入口。
- 在通过兼容层运行 ARM64 应用的 Android 上，读取维护目录和导出诊断记录时使用系统对应的目录标志。
