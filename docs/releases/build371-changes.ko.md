# DSHA 0.2.2-rc.5-20261119.0600-dsh0.2.2-rc.5 / build371

- 앱과 내장 DSH의 버전은 모두 0.2.2-rc.5입니다. 로컬 Standard 빌드는 기존 패키지 이름 `dsh.android.client`와 E7E3 서명을 사용하며 Android 11 이상 arm64 기기를 지원합니다.
- 기본 터미널 인수가 비어 있을 때 터미널 세션을 만들 수 없던 문제를 수정했습니다.
- 환경 작업이 실행 중일 때 시작을 요청하면 작업이 끝난 뒤 앱이 시작을 계속합니다. 시작 과정에서 중복되는 환경 준비와 플러그인 등록을 줄였습니다.
- 네이티브 화면을 스크롤할 때 중복으로 그리는 배경과 웹 페이지를 스크롤할 때의 중복 처리를 줄였습니다.
