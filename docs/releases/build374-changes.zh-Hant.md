# DSHA 0.2.2-rc.5-20261119.2300-dsh0.2.2-rc.5 / build374

- 應用程式與內建 DSH 均為 0.2.2-rc.5。Android 11 及以上的 arm64 裝置可使用原有 E7E3 簽章更新 `dsh.android.client`。
- 改善傳統 proot 下的啟動和外掛讀取，修正於首頁檢查所有外掛更新時可能退回桌面的問題。修正開啟外掛安裝連結或關閉外掛安全模式時可能閃退的問題。修正外掛卡片已顯示新版本，點按更新卻誤報環境變更的問題。
- 調整載入視窗的文字對齊，移除「待驗證」標籤。網頁外掛頁面僅列出使用者可管理的外掛，Android 殼層整合仍由應用程式提供。修正網頁外掛更新失敗後可能無法繼續使用舊版的問題。移除舊版內建讀取提示外掛。
- 設定中的常亮與省電選項支援整列點按，並改善行動網頁切換面板時的動畫回饋。
- 外掛列表自動重新整理後，仍可在檢查更新按鈕旁查看最近一次手動檢查的結果。
- 「跟隨系統」與手動指定的語言相同時，重新開啟語言選擇框也會勾選剛儲存的選項。
- 平板開啟設定時，安裝頁面會先顯示。環境狀態和版本會在背景讀取，完成後自動填入。
- 修正尚未安裝執行環境時進入有限模式會閃退的問題。缺少健康檢查記錄時，維護頁面也能繼續檢查環境。修正沒有待移轉的舊資料時，安全啟動或快速停止後，下次正常啟動可能遭阻擋的問題。復原頁面會說明已知原因，並提供查看詳細資訊的入口。
- 在透過相容層執行 ARM64 應用程式的 Android 上，讀取維護目錄和匯出診斷記錄時會使用系統對應的目錄旗標。
