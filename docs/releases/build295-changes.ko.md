# DSHA 0.2.1-rc.5-20261103.1500-dsh0.2.1-rc.5 / build295

## 태블릿, 긴 대화와 스트리밍 응답

- SSE 호환성: data 없는 이벤트 블록을 올바르게 처리합니다. EOF의 완전한 JSON을 허용하는 SDK 동작을 유지하며 손상된 JSON은 명확히 실패합니다.
- 긴 대화에서 반복 변환과 컴포넌트 생성을 줄입니다. 세션 상태를 증분 갱신하고 깊은 재귀 없이 작업 공간 분기 순서를 유지합니다.
- 태블릿의 전체 페이지 탐색을 줄입니다. 높은 화면 주사율과 테마 샘플링은 동일 입력을 재사용하며 포커스, 화면, 설정, 페이지 세대 변경 검사를 유지합니다.
- 시작 시 중복 APK 읽기를 줄이고 선택적 Python 모듈을 필요할 때 가져옵니다. 권한, 데이터 디렉터리, 오류 처리 경계는 유지합니다.
- 정식 환경과 독립 복구 환경은 동일한 아카이브 바이트를 공유하여 APK 크기를 유지합니다. 실행 디렉터리와 수명 주기는 독립적입니다.
- 호스트, 브라우저, 기기 검증을 별도로 기록합니다. 실제 결과는 전달 보고서를 따르며 고정 속도 향상이나 모든 과거 데이터 형태를 보장하지 않습니다.
