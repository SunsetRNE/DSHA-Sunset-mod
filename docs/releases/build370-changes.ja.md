# DSHA 0.2.1-rc.5-20261119.0400-dsh0.2.2-rc.5 / build370

- バージョンコードを 370 に更新しました。ローカルの Standard 版は DSHA のパッケージ名 `dsh.android.client` と従来の E7E3 署名証明書を引き継ぎ、Android 11 以降の arm64 端末に対応します。
- 同梱の DSH を 0.2.2-rc.5、モバイル UI の dsh-web-mobile を 3.3.5 に更新しました。起動、実行環境のメンテナンス、プラグイン管理、ターミナルセッション、自動バックアップに関する上流の変更を取り込みました。
- アプリ間のファイルアクセスにシステムのファイル選択画面を使用します。ディレクトリのアクセス権を保存できなかった場合の、権限範囲の縮小と取り消しの処理を改善しました。
- 同じパッケージ名と署名で build308 に上書きインストールすると、初回起動時に実行環境のメンテナンスが必要になる場合があります。既存の環境を確認し、必要に応じて実行環境の更新を案内します。
