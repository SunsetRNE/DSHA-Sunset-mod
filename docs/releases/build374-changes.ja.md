# DSHA 0.2.2-rc.5-20261119.2300-dsh0.2.2-rc.5 / build374

- アプリと同梱の DSH はともに 0.2.2-rc.5 です。Android 11 以降の arm64 端末では、従来の E7E3 署名で `dsh.android.client` を更新できます。
- 従来の proot での起動とプラグインの読み込みを改善しました。すべてのプラグインの更新を確認すると Android のホーム画面に戻ることがある問題を修正しました。プラグインのインストールリンクを開いたときや、プラグインのセーフモードを解除したときにアプリがクラッシュする問題を修正しました。プラグインに新しいバージョンが表示されているのに、更新時に環境が変わったと誤って表示され、更新できない問題を修正しました。
- 読み込みダイアログのテキストの配置を調整し、確認待ちラベルを削除しました。Web のプラグイン画面にはユーザーが管理できるプラグインだけが表示されます。Android シェル連携は引き続きアプリが提供します。Web でのプラグイン更新に失敗した際、以前のバージョンを使えなくなることがある問題を修正しました。旧内蔵の読み取りヒントプラグインを削除しました。
- 画面を常時点灯する設定と省電力設定は、行全体をタップして変更できます。モバイル Web のパネル切り替えも改善しました。
- プラグイン一覧が自動更新された後も、直近の手動チェックの結果を更新確認ボタンの横で確認できます。
- システムの言語と手動で選んだ言語が同じ場合も、言語選択画面を開き直すと保存した項目にチェックが付きます。
- タブレットで設定を開くと、インストール画面が先に表示されます。環境の状態とバージョンはバックグラウンドで読み込み、完了後に表示します。
- 実行環境のインストール前に制限モードを開くとアプリが終了する問題を修正しました。正常性の記録がまだない環境でも、メンテナンスで確認を続けられます。移行が必要な旧データがない場合に、セーフ起動やすぐに停止した後の通常起動が妨げられる問題を修正しました。復旧画面では、判明している原因と詳細を確認できます。
- ARM64 アプリを互換レイヤーで実行する Android では、メンテナンス用ディレクトリの読み取りと診断記録の書き出しに、そのシステムに合ったディレクトリフラグを使います。
