# DSHA 0.2.2-rc.5-20261119.0600-dsh0.2.2-rc.5 / build371

- アプリと同梱の DSH はどちらも 0.2.2-rc.5 です。ローカルの Standard 版は `dsh.android.client` と既存の E7E3 署名を使用し、Android 11 以降の arm64 端末に対応します。
- 既定のターミナル引数が空の場合にセッションを作成できない問題を修正しました。
- 環境の処理中に起動を要求した場合は、その処理が終了してから起動を続けます。起動時に環境の準備やプラグインの登録を重複して行う処理を減らしました。
- ネイティブ画面のスクロール時に背景を重複して描画する処理と、ウェブページのスクロール時に重複して行う処理を減らしました。
