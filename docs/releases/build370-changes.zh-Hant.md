# DSHA 0.2.1-rc.5-20261119.0400-dsh0.2.2-rc.5 / build370

- 版本碼提升為 370。本機 Standard 版沿用 DSHA 的安裝套件名稱 `dsh.android.client` 與既有 E7E3 簽章，支援 Android 11 以上的 arm64 裝置。
- 內建 DSH 更新至 0.2.2-rc.5，內建行動介面 dsh-web-mobile 同步至 3.3.5。納入上游對啟動與執行環境維護、外掛管理、終端機工作階段和自動備份的更新。
- 跨應用程式檔案存取使用系統檔案選擇器。上游改善了目錄授權儲存失敗時，對縮小授權範圍與撤銷操作的處理。
- 從 build308 以相同套件名稱及簽章覆蓋安裝後，首次進入時可能需要維護執行環境。應用程式會檢查舊環境與目前版本的相容性，並在需要時提供「更新執行環境」入口。
