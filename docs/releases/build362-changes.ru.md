# DSHA 0.2.1-rc.5-20261113.1000-dsh0.2.2-rc.1 / build362

- Сборка инженерной инфраструктуры (без нового пользовательского интерфейса): после build361 сборка build362 включает пакет Kotlin-инструментария, обходной путь Rust R0, A2 «хранение и файлы» slice1+2, а также проектные документы A7 / R1 и документ приёмки build361 на устройстве. **Пакеты Kotlin и Rust — это инфраструктура сборки / форматирования / нативного обходного пути, они не меняют видимое поведение**; A2 — замена слоя возможностей / реестра, она также не добавляет пользовательского интерфейса.
- Kotlin-инструментарий (инженерия): AGP 9.1.1 built-in Kotlin, KGP закреплён на 2.2.10 (плагин `org.jetbrains.kotlin.android` не применяется), jvmTarget 17; ktfmt 0.64 `--kotlinlang-style` включён в шлюз форматирования и CI (`tools/format-kotlin-tree.py --check`); `util/ShellQuote` целиком перенесён на Kotlin, поведение эквивалентно, форма вызовов из Java не изменилась; видимое поведение не меняется.
- Обходной путь Rust R0 (инженерия, без упаковки в APK): добавлены crate `rust/`, офлайн-vendor из 16 crate (782 файла / 7 384 177 B) и фиксация инструментария; `tools/rust/build.py` отвечает за сборку и побайтовую воспроизводимость, а также готовы шлюзы ELF / границ / APK и четыре режима CI (check / repro / native / differential). **R0 не подключён к упаковке APK, `.so` не входит в пакет**; APK получает только полные тексты лицензий (34 файла / 170 896 B, около 171 КБ несжатого текста); видимое поведение не меняется.
- Хранение и файлы A2 slice1+2 (слой возможностей, без нового UI): slice1 реализует слой возможностей реестра разрешений SAF (реестр, поколения, дескрипторы возможностей, лимиты и границы) и исправляет три P2, переданные на выходе A1 (порядок блокировок / очистка / изоляция тестов); slice2 переносит `SafGrants` в реестр разрешений, сохраняет старый `saf_grants` как однократную совместимость только для чтения с откатом на старый путь при неудачной миграции, а старые id / tree URI немедленно перестают действовать после отзыва или повторной авторизации. P1 + пять P2 рецензии не-реализатора и последующие N1/N2 исправлены (N3/N4 записаны как известные окна и отложены до slice3/4); конечные точки `/app/saf/*` и `BRIDGE_PROTOCOL=3` не меняются, а UI рабочей среды остаётся в slice3 (в этой сборке не сделан).
- Влияние обновления поверх: A2 меняет `saf/`, который находится внутри `launcherInputs` `runtime-descriptor` (481→488), поэтому `runtimeId` становится **`a2847544e7032bdd0eb7394438455521c120a25c0d54c280eb32db7a3e3e6139`**; **первый запуск после обновления 361→362 один раз открывает страницу обслуживания управляемой среды выполнения** и выполняет пробный запуск управляемой среды, как и ожидается, личные данные сохраняются. fixed-inputs остаются замороженными на `fixed-inputs-20261105e`, встроенный `dsh-web-mobile` 3.3.5 и его включение по умолчанию не меняются.
- Проектные документы и приёмка (только документы): проверка проектирования возможностей устройства A7 (сопоставление прав Root и встроенный клиент ADB, проверено только чтением по коду build361, без действий на устройстве) и план Rust R1 (инструментарий, vendor, лицензии, четыре режима CI и выравнивание страниц 16 КБ) внесены в индекс документации; документ приёмки build361 на устройстве (OnePlus 12, 358→360→361, нулевое обслуживание на 360→361, READY, «О программе и лицензии» проверено) сохранён в архиве.
