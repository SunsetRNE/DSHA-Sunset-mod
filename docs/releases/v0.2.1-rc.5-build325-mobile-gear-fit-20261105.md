# build325 变更与已知问题（草稿，2026-11-05）

> 真机验收结论按实际结果补写在本文件末尾；**未写「已通过」之前不代表验收通过**。

## 一、build324 的已知问题（本版针对）

| 现象 | 记录 |
|---|---|
| build323 覆盖安装 build324 后主界面整页白屏 | 用户真机复现；禁用内置插件 `dsh-web-mobile` 后白屏与侧栏重复都消失 |

| 维护页出现但未自动开始环境更新，「进入主界面」压在维护提示之上 | 另有会话按维护门禁（T60）排查，**本版不含该修复** |

## 二、根因判断

**已证实的部分**（补丁链侧取证见
[build324 白屏排查](v0.2.1-rc.5-build324-blank-screen-20261105.md)）：

- build323 → build324 的受管运行树**只差两条补丁**（`@deepseek-ai/dsh-client-ui-settings-general`、
  `@deepseek-ai/dsh-tool-skill` 各一份模块 × 树内两份拷贝），无新增/删除文件；两条补丁逐字节
  反向应用可还原到声明的 `sourceSha256`，`node --check` 通过，不存在「应用失败被静默忽略」。
- 手机上唯一客户端可见差异：手机是 drawer 模式（`viewport < 768`），`wide` 为真，
  宿主 `ConnectionIndicator` 本来真实渲染；T58 让首次连接不再渲染它。
- 上游 `dsh-web-mobile` 3.2.2 的 `drawer-quick-settings-chip-guard` 用
  `:has(> button[data-phase], > [role="status"])` 判断「这一行有没有指示灯」来决定 footer
  齿轮的让位——**插件的渲染依赖宿主某个子节点存在**，宿主一改首次连接的渲染方式，口径就失准。

**未证实的部分**：白屏的直接触发栈仍未取得（主 WebView 没有原生 console 捕获），
因此本版是「去掉插件对宿主节点的依赖」的对症修复，**不宣称已定位白屏根因**。
真机覆盖安装验证通过后，才能把这条差异确认为白屏/重复的唯一原因；若验证仍复现，
下一步按排查文档第 7 节取证后改走「扣留 T58 + 重建固定输入」的方案。

## 三、本版改动

1. `tools/apply-mobile-client-patches.mjs` 新增 `DSHA_GEAR_FIT_V1`：
   - 守卫规则改为只认插件自己的属性
     `[data-mobile-nav="quick-settings-wrap"][data-mobile-nav-quick-fit="0"]`，不再 `:has()` 宿主节点；
   - `gearAvailable()` 改为实测行内容宽度与其它可见孩子宽度和，纯判据
     `dshaGearFits(rowWidth, usedWidth)` 导出给宿主测试；行宽不可用时保守让位；
   - `syncMenuEntry` 用同一个结论决定是否收起账户菜单设置项，保证任何时刻只有一条设置入口。
   - 重新生成 `app/src/main/assets/builtin-plugins/dsh-web-mobile/lib/client.js`（APK 资源，
     **不涉及 `dsh-runtime.bin`，不需要重建固定输入包**）。
2. 新增宿主回归测试 `tools/test-mobile-gear-contract.mjs`（已登记 `tools/host-tests.manifest.json`）：
   用最小 DOM 语义跑真实产物，覆盖「没有指示灯时契约仍成立」「指示灯出现后让位、消失后恢复」
   「行宽不足保守让位」「重复 `ensure` 幂等」。
3. 文档：[移动插件本地补丁](../web-mobile-patches.md) 新增本补丁一节。

## 四、T58（`first-connect-indicator-patch.json`）是否保留

**保留。** 本版不改 `runtime-patches.json`、不改 `dsh-runtime.bin`、不重建固定输入包。
首连不再显示黄色/绿色提示的行为按 build324 原样保留；本版只是让移动壳不再依赖那个提示元素。

## 五、已知问题（本版未修）

- 维护页把「进入主界面」放在维护提示之上、覆盖升级未自动开始环境更新：由维护门禁会话
  （T60）单独修复，**不在本版**。
- 白屏的直接触发栈仍缺设备证据；本版按插件契约修复推进，真机若仍复现按排查文档改走扣留 T58。
- 内置 `dsh-web-mobile` 仍是上游 3.2.2 + DSHA 本地补丁，本版不升级上游。
