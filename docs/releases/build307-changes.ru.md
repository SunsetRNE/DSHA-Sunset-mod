# DSHA 0.2.1-rc.5-20261104.0200-dsh0.2.1-rc.5 / build307

- Обновлён встроенный мобильный интерфейс; улучшены обработка прокрутки длинных диалогов и поиск якорей.
- Улучшена обработка завершения веб-рендерера, поворота экрана, полноэкранного режима и экранной клавиатуры.
- Сокращены повторные проверки при запуске, добавлена диагностика запуска и фонового состояния; улучшены удаление временных плагинов и обновление статуса.
