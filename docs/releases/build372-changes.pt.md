# DSHA 0.2.2-rc.5-20261119.1448-dsh0.2.2-rc.5 / build372

- O aplicativo e o DSH integrado usam a versão 0.2.2-rc.5. Dispositivos arm64 com Android 11 ou posterior podem atualizar `dsh.android.client` com a assinatura E7E3 existente.
- Nas configurações de destino de inicialização do navegador integrado, é possível voltar à tela inicial do DSHA. Abra a página novamente para retomar a conversa.
- Registros de ferramentas com identidade desconhecida aparecem como texto somente leitura. A troca de conversa cancela a verificação da página anterior. Os diagnósticos de rotina são gravados em segundo plano.
- O gerenciamento de armazenamento mostra os itens que podem ser limpos, os motivos para manter os demais e o espaço disponível antes e depois da limpeza.
