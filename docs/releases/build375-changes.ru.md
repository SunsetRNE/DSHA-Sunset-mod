# DSHA 0.2.2-rc.5-20261122.1650-dsh0.2.2-rc.5 / build375

- Приложение и встроенный DSH используют версию 0.2.2-rc.5. На устройствах arm64 с Android 11 или новее `dsh.android.client` обновляется с прежней подписью E7E3.
- При изменении или выборочном восстановлении настроек рабочей области сохраняются только изменённые параметры. Остальные сохраняют прежние значения или продолжают наследовать значения по умолчанию. Если изменить только переключатель или только список моделей в пуле субагентов, сохраняется лишь изменённый параметр, а второй продолжает следовать изменениям своего значения по умолчанию, если уже наследовал его. Если в настройках повторных попыток пользовательского поставщика задано только их число, то после изменения одного лишь отображаемого имени режим повторных попыток по-прежнему наследует значение по умолчанию.
- После возврата из фона или обновления DSHA повторно проверяет прежний экземпляр рабочей области, чтобы завершившийся экземпляр не мешал запуску. Если после обновления открыть главный экран во время очистки старых копий, DSHA дождётся возможности продолжить обновление среды выполнения. Это предотвращает ошибочное сообщение о сбое проверки готовности.
- Журнал запуска показывает момент окончания отсчёта. Сообщения после готовности веб-интерфейса помечаются временем работы и учитываются отдельно от запуска.
- Если при запуске выбрана веб-область, она открывается и при нажатии значка приложения, когда его главный экран остался в фоне. Если среде требуется обслуживание или нужно проверить предыдущую рабочую область, приложение остаётся на своём экране.
- При сохранении копии файла из клона приложения сообщение об успехе появляется после завершения записи. Если отключить ADB на экране сопряжения беспроводной отладки и вернуться на страницу канала управления устройством, переключатель будет выключен. После завершения, тайм-аута или прерывания фоновой проверки подключения ADB приложение завершает процессы этой проверки и сохраняет существующее беспроводное сопряжение.
- В настройках виртуального экрана одновременно видны описание и доступные варианты. Отмена сохраняет текущий выбор. Если при открытии узлов виртуального экрана служба специальных возможностей DSHA не подключена, приложение сообщает, что служба недоступна.
- Удаление поставщика моделей удаляет его настройки из текущего профиля и сохраняет общий ключ API. Чтобы удалить и поставщика, и ключ, сначала очистите ключ на странице редактирования этого поставщика и сохраните настройки, а затем удалите поставщика. При отклонении изменений настроек ключ сохраняется.
- При смене языка, синхронизируемого с приложением, текущая веб-область обновляется на месте. Если рабочая область уже открыта, после переключения светлой и тёмной тем можно вернуться к той же веб-странице. Настройка настольного вида применяется при создании нового веб-представления. Текст и кнопки открытого отчёта об ошибке тоже обновляются. Действие для просмотра причины и способов исправления открывает экран восстановления. Возврат ведёт на главный экран приложения.
- В резервную копию только настроек входят переносимые настройки приложения, конфигурации моделей, профили и предустановки. Установочные пакеты плагинов и дубликаты архивов исключены из этой копии. Поддерживаемые старые настройки и пользовательские декларации профилей сохраняются. Поле ключа API приложения управляется отдельной опцией. Для полной копии приложения и ранее сохранённых архивов остаются отдельные способы восстановления.
- В статистике хранилища отмечаются частично прочитанные категории и показывается уже подсчитанный размер. Непрочитанный размер обозначается как неизвестный. Для подтверждённо пустой категории отображается 0 B.
- В карточке навыка сначала показывается предварительный просмотр. Полный исходный текст можно открыть и читать по страницам. При перемещении в «Недавно удалённые» или восстановлении карточка остаётся видимой. После завершения операции элементы управления снова доступны.
