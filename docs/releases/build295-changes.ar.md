# DSHA 0.2.1-rc.5-20261103.1500-dsh0.2.1-rc.5 / build295

## الأجهزة اللوحية والمحادثات الطويلة والاستجابات المتدفقة

- توافق SSE: معالجة كتل الأحداث التي لا تحتوي على data بصورة صحيحة. يبقى سلوك SDK لقبول JSON الكامل عند EOF، بينما يفشل JSON التالف برسالة واضحة.
- تقليل التحويل المتكرر وإعادة إنشاء المكونات في المحادثات الطويلة. تحديث حالة الجلسة تدريجياً مع الحفاظ على ترتيب فروع مساحة العمل دون استدعاء تكراري عميق.
- تقليل مسح الصفحة الكاملة في واجهة الجهاز اللوحي. إعادة استخدام المدخلات الثابتة لمعدل التحديث المرتفع ولون الواجهة مع إبقاء فحوص التركيز والشاشة والإعدادات وجيل الصفحة.
- تقليل قراءة مدخلات APK المتكررة عند التشغيل، وتحميل وحدات Python الاختيارية عند الحاجة. تبقى حدود الأذونات والبيانات والأخطاء محفوظة.
- تشارك البيئة الأساسية وبيئة الطوارئ المستقلة بايتات الأرشيف نفسها للحفاظ على حجم APK، مع بقاء مجلدات التشغيل ودورات الحياة مستقلة.
- تسجل نتائج المضيف والمتصفح والجهاز بشكل منفصل في تقرير التسليم. لا يوجد وعد بتسريع ثابت أو تغطية جميع أشكال البيانات التاريخية.
