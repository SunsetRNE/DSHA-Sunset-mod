# DSHA 0.2.2-rc.5-20261119.1852-dsh0.2.2-rc.5 / build373

- Приложение и встроенный DSH используют версию 0.2.2-rc.5. На устройствах arm64 с Android 11 или новее `dsh.android.client` обновляется с прежней подписью E7E3.
- При подсчёте занятого места и очистке отображаются индикатор хода работы, текущий этап и число обработанных элементов.
- В разделе хранилища и файлов откройте список копий среды для отката. Для каждой копии видны её размер и причина хранения.
- На странице плагинов можно увидеть уже известный список во время проверки. Кнопка обнаружения запускает новую проверку и показывает её состояние.
- При ручной очистке старую копию DSH можно сжать после сверки журнала операции и содержимого файлов. На странице сведений её можно распаковать в прежнее расположение. Допуск к откату среды при этом сохраняет прежнее значение.
