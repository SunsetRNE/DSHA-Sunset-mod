# DSHA 0.2.2-rc.5-20261119.2300-dsh0.2.2-rc.5 / build374

- Приложение и встроенный DSH используют версию 0.2.2-rc.5. На устройствах arm64 с Android 11 или новее `dsh.android.client` обновляется с прежней подписью E7E3.
- Улучшены запуск и чтение плагинов в классическом proot. Исправлен возможный выход на главный экран Android при проверке обновлений всех плагинов. Исправлены сбои при открытии ссылки для установки плагина и при отключении безопасного режима плагинов. Исправлено ложное сообщение об изменении среды, из-за которого не удавалось обновить плагин после обнаружения новой версии.
- Текст окна загрузки выровнен, метка ожидания проверки убрана. На странице плагинов в веб-интерфейсе показаны только плагины, которыми может управлять пользователь. Интеграции оболочки Android по-прежнему доступны в приложении. Исправлена проблема, из-за которой предыдущая версия плагина могла стать недоступной после неудачного обновления через веб-интерфейс. Старый встроенный плагин подсказок при чтении удалён.
- Для настройки постоянной подсветки экрана и энергосбережения можно нажать на всю строку. Улучшены переходы панелей в мобильном веб-интерфейсе.
- После автоматического обновления списка плагинов результат последней ручной проверки остаётся виден рядом с кнопкой проверки обновлений.
- При повторном открытии списка сразу виден сохранённый выбор, даже если выбранный вручную язык совпадает с языком системы.
- На планшетах при открытии настроек сначала появляется панель установки. Состояние среды и версии отображаются после чтения в фоновом режиме.
- Исправлен сбой при открытии ограниченного режима до установки среды выполнения. Проверка среды при обслуживании работает и при отсутствии записи о её состоянии. Исправлена блокировка обычного запуска после безопасного запуска или быстрой остановки, когда перенос старых данных не требуется. На странице восстановления указаны известные причины и можно открыть подробности.
- В системах Android с трансляцией приложений ARM64 обслуживание и экспорт диагностики используют правильные для системы флаги открытия каталогов.
