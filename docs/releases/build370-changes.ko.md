# DSHA 0.2.1-rc.5-20261119.0400-dsh0.2.2-rc.5 / build370

- 버전 코드를 370으로 올렸습니다. 로컬 Standard 빌드는 DSHA 패키지 이름 `dsh.android.client`와 기존 E7E3 서명 인증서를 사용하며, Android 11 이상의 arm64 기기를 지원합니다.
- 내장 DSH를 0.2.2-rc.5로, 모바일 UI dsh-web-mobile을 3.3.5로 업데이트했습니다. 시작, 런타임 유지 관리, 플러그인 관리, 터미널 세션과 자동 백업에 대한 업스트림 변경을 반영했습니다.
- 앱 간 파일 접근에는 시스템 파일 선택기를 사용합니다. 디렉터리 권한 저장에 실패했을 때 권한 범위 축소와 철회를 처리하는 방식이 개선되었습니다.
- 동일한 패키지 이름과 서명으로 build308을 덮어쓰면 처음 실행할 때 런타임 유지 관리가 필요할 수 있습니다. 앱은 기존 환경을 확인하고 필요한 경우 런타임 업데이트를 안내합니다.
