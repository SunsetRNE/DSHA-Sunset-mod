# DSHA 0.2.2-rc.5-20261119.1448-dsh0.2.2-rc.5 / build372

- Приложение и встроенный DSH используют версию 0.2.2-rc.5. На устройствах arm64 с Android 11 или новее `dsh.android.client` обновляется с прежней подписью E7E3.
- Из настроек цели запуска во встроенном браузере можно вернуться на главный экран DSHA. При повторном открытии страницы можно продолжить тот же разговор.
- Записи инструментов с неопознанным идентификатором отображаются как текст только для чтения. При смене разговора проверки предыдущей страницы отменяются. Обычные диагностические записи сохраняются в фоне.
- В разделе управления хранилищем показаны объекты для очистки, причины сохранения остальных объектов и доступное место до и после очистки.
