# DSHA 0.2.2-rc.5-20261119.1852-dsh0.2.2-rc.5 / build373

- アプリと同梱の DSH はともに 0.2.2-rc.5 です。Android 11 以降の arm64 端末では、従来の E7E3 署名で `dsh.android.client` を更新できます。
- ストレージの集計とクリーンアップに、進捗バー、現在の工程、処理済み件数を表示します。件数はスキャン中も更新されます。
- 「ストレージとファイル」でランタイムの復元用コピーを開くと、それぞれの使用容量と保持されている理由を確認できます。
- ホームからプラグイン画面を開くと、確認中でも取得済みの一覧を表示できます。検出ボタンを押すと再確認し、検証状態を表示します。
- 手動クリーンアップでは、更新記録とファイル内容を照合できた古い DSH コピーを圧縮できます。詳細画面で元の場所に展開できます。実行環境をその版に戻せる条件は変わりません。
