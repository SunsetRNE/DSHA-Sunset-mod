# DSHA 0.2.1-rc.5-20261104.0200-dsh0.2.1-rc.5 / build307

- 내장 모바일 UI를 업데이트하고 긴 대화의 스크롤 처리와 앵커 검색을 개선했습니다.
- 웹 렌더러 종료, 화면 회전, 전체 화면 및 키보드 레이아웃 처리를 개선했습니다.
- 시작 시 중복 검사를 줄이고 시작 및 백그라운드 상태 진단을 추가했습니다. 임시 플러그인 제거와 상태 갱신도 개선했습니다.
- 백업 임시 파일 관리를 개선했습니다. 백업이 완료되지 않으면 진단 자료를 보존하고 더 명확한 오류 정보를 제공합니다.
- 외부 네트워크를 사용할 수 없을 때 기기 내부의 웹 연결이 오프라인으로 잘못 판단되는 문제를 수정했습니다.
