# DSHA 0.2.2-rc.5-20261122.1650-dsh0.2.2-rc.5 / build375

- 應用程式與內建 DSH 均為 0.2.2-rc.5。Android 11 及以上的 arm64 裝置可使用原有 E7E3 簽章更新 `dsh.android.client`。
- 修改或還原選取的工作台設定時，只儲存實際變更的項目。其他設定保留原值或繼承狀態。在子代理模型池中，單獨切換開關或編輯模型清單時只儲存變更的一項，另一項若原本跟隨預設值，就會繼續隨預設值更新。自訂供應商的重試設定只設定了次數時，單獨修改顯示名稱，重試模式仍會跟隨預設值。
- 從背景恢復或更新後，重新核對原工作台執行個體，避免已退出的執行個體阻擋啟動。更新後開啟首頁時，若背景正在清理舊副本，應用程式會稍候，等可以繼續時自動更新執行環境，避免誤報環境檢查失敗。
- 啟動記錄顯示啟動計時截止的位置。網頁就緒後的記錄會標示執行時間，不再計入啟動階段。
- 將啟動位置設為網頁工作台後，從桌面點開仍在背景的原生首頁，也會依照這個選擇進入工作台。需要維護環境或確認上一個工作台時，會留在原生頁面處理。
- 雙開中的檔案另存會等寫入完成才提示成功。從無線偵錯配對頁關閉 ADB 後，返回裝置執行通道頁即可看到開關已關閉。背景 ADB 連線檢查完成、逾時或中斷後，應用程式會回收這次檢查的程序，保留現有無線配對。
- 虛擬螢幕規格會同時顯示說明和可選的規格。取消會保留原有選項。開啟虛擬螢幕節點時，若 DSHA 無障礙服務尚未連線，畫面會提示服務無法使用。
- 在模型設定中刪除供應商，會移除目前設定檔的供應商設定並保留共用的 API 金鑰。若也要清除金鑰，請先到該供應商的編輯頁清除並儲存，再刪除供應商。設定修改被拒時會保留原金鑰。
- 在工作台切換與應用程式同步的語言時，介面會就地更新並保留目前的工作台。工作台已開啟時，切換淺色或深色主題後返回，會繼續顯示原本的網頁。桌面版面配置會在建立新的網頁檢視時生效。已開啟的故障說明也會更新內文和按鈕。「查看原因與修復」會開啟修復頁，返回後再回到原生首頁。
- 「僅設定」會收集可移轉的原生設定、模型設定、工作設定檔和預設。原先誤納入的外掛安裝套件和重複壓縮檔已移出此範圍。支援的舊設定和使用者寫入設定檔聲明的內容會保留。是否納入原生 API 金鑰欄位由獨立選項決定。完整應用程式備份與舊保留檔仍使用各自的還原入口。
- 儲存空間統計會標示讀取不完整的類別，並顯示已讀取的大小。無法取得大小的類別顯示未知，確認空白的類別顯示 0 B。
- 技能詳情會先顯示預覽，開啟完整原始內容後可逐頁閱讀。移到最近刪除或還原期間，詳情保持可見，作業完成後可繼續操作。
