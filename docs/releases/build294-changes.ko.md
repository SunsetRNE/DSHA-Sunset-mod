- 실험적: 플러그인 백그라운드 검사는 플러그인 페이지가 보일 때만 실행합니다. Web 직접 진입과 알림·최근 앱을 통한 복귀에서도 시작 대상을 유지하며, Web 설정에서도 시작 대상을 선택할 수 있습니다.
- 기기 브리지 포트가 공개되지 않았거나 읽기에 실패하면 오류를 반환합니다. 3090으로 대체하여 현재 설치의 인증 정보를 보내지 않습니다. 실험적 `/app/install`은 컨테이너 APK를 시스템 설치 프로그램에 전달하며, 사용자 확인은 여전히 필요합니다. 백그라운드에서는 알림을 통해 설치 화면을 엽니다.
- 실험적: 네트워크 상태 진단이 네트워크 제한, 서비스 및 DNS 문제, 프로세스 동결 징후를 보고합니다. 자동으로 복구하지 않습니다.

## 로컬 시작 및 홈 화면 조정

- 시작 단계의 중복 검사와 디스크 읽기를 줄이되, 런타임 무결성 검사와 실패 처리는 유지합니다.
- 서비스 준비 완료 이벤트를 받으면 홈 화면을 즉시 갱신하고 다음 주기적 갱신을 기다리지 않고 Web 진입을 이어갑니다. 준비 상태 확인은 생략하지 않습니다.
- 넓은 화면과 좁은 화면 모두 홈 화면 왼쪽에 다시 시작, 오른쪽에 중지를 배치합니다. 오른쪽에서 왼쪽으로 쓰는 언어는 기존처럼 시스템 레이아웃 방향을 따릅니다.
- 높은 주사율, 움직이는 화면 탭, 환경 파일 관리 수정을 유지합니다. APK 용량 최적화도 유지하며, 일반 환경과 복구 환경의 아카이브는 다이제스트가 같을 때만 패키지 내부 데이터를 공유합니다. 실행 디렉터리는 계속 독립적으로 유지합니다.
