# DSHA 0.2.2-rc.5-20261119.0600-dsh0.2.2-rc.5 / build371

- Версия приложения и встроенного DSH — 0.2.2-rc.5. Локальная сборка Standard использует пакет `dsh.android.client` и существующую подпись E7E3. Поддерживаются устройства arm64 с Android 11 и новее.
- Исправлено создание сеанса терминала при пустом списке аргументов по умолчанию.
- Если запустить приложение во время выполнения задачи среды, запуск продолжится после её завершения. При запуске стало меньше повторных операций подготовки среды и регистрации плагинов.
- Сокращено число повторных отрисовок фона при прокрутке интерфейса приложения и повторных операций при прокрутке веб-страниц.
