# DSHA 0.2.1-rc.5-20261115.1335-dsh0.2.2-rc.1 / build367

- APK 更新（M17）：更新檢查改為由使用者主動觸發；啟動、返回、視窗取得焦點和首次開啟更新頁面時，不再自動檢查或顯示升級提示。下載與序列任務由應用程式層級的擁有者管理，頁面重建後繼續觀察原任務；授權與安裝結果只延續使用者的原請求，失效回呼不建立新請求，UNKNOWN 不重放。
- 內建外掛啟用（T2）：修復已安裝且具有精確受管證明的內建外掛，被誤套用第三方匯入規則而無法啟用的問題。自動預設停用標記與使用者主動停用分開記錄；使用者停用及來源不明的歷史空白標記均予保留，不因升級覆寫。內建 dsh-web-mobile 3.3.5 版本與預設啟用政策維持不變。
- 啟動復原（S1a/S1b）：新增停止事實的 Kotlin 影子取樣與純交接契約；S1a 只記錄事實，不替換原停止判準。S1b 僅在受保護復原、且未指定停用外掛的狹窄路徑中，一次性消耗交接證明，執行前仍核對目前身分與現場狀態；未進入交接時，不符合條件仍走原流程，進入後遇到 UNKNOWN、物件變動或許可失效則直接阻斷，不視為快取未命中而重放。一般啟動與手動停止維持原流程。這不是所有路徑的退出證明，也不會僅憑 PID 或連接埠終止程序。
- 備份串流橋接（A3）：接入 Rust envelope 串流橋接，並凍結有界串流、失敗及清理契約；預設後端仍為 JVM，Rust 路徑必須同時符合既有啟用與可用條件。已選 Rust 的串流失敗後，不切換至 JVM 重新讀取或寫入。v5 封存格式、完整性核驗與還原語意維持不變；APK 的 off 模式不隨包提供 Rust 程式庫，本版不宣稱已完成真正 Android Rust 串流或斷電復原的裝置驗收。
- Kotlin 遷移：contract 整個職責域的 18 個檔案、M17 的 4 個檔案，以及 SAF 15 個、下載傳輸 8 個、網路健康 3 個 Java 檔案遷移為 Kotlin，分別核對實際 Java 呼叫點與既有行為。ABI 回執明確記錄可見性、final 和編譯器新增成員等邊界；contract 的 7 個原 Java record 不保留 record 中繼資料，不宣稱 ABI 逐位元完全相同。SAF「跨應用程式檔案存取」、下載佇列、復原／發布與網路健康規則維持既有語意，不新增 Manifest 權限或資料格式。
- A8-P1 工程基礎：固定工具鏈與建置慣例、共用原始碼配置、編譯來源證明、全儲存庫新鮮測試彙整、凍結測試身分基準及 unit contract proof 納入門檻；產生器來源與 93 項執行階段配方同步。第三方聲明掃描涵蓋 build-logic，修正 release 工作流程 off 選項被 YAML 轉為布林值，以及主 Java 編譯證明缺項；原始碼衛生的 UUID 掃描擴展至 `.kt`。
