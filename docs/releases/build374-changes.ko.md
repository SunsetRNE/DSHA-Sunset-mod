# DSHA 0.2.2-rc.5-20261119.2300-dsh0.2.2-rc.5 / build374

- 앱과 내장 DSH의 버전은 모두 0.2.2-rc.5입니다. Android 11 이상 arm64 기기에서 기존 E7E3 서명으로 `dsh.android.client`를 업데이트할 수 있습니다.
- 기존 proot 엔진의 시작 및 플러그인 읽기를 개선했습니다. 모든 플러그인 업데이트를 확인할 때 Android 홈 화면으로 돌아가는 문제를 수정했습니다. 플러그인 설치 링크를 열거나 플러그인 안전 모드를 끌 때 앱이 종료되는 문제를 수정했습니다. 플러그인 카드에 새 버전이 표시되는데도 환경이 변경되었다는 잘못된 안내로 업데이트가 막히는 문제를 수정했습니다.
- 로딩 창의 텍스트 정렬을 맞추고 확인 대기 라벨을 제거했습니다. 웹 플러그인 화면에는 사용자가 관리할 수 있는 플러그인만 표시됩니다. Android 셸 연동은 앱에서 계속 제공합니다. 웹에서 플러그인 업데이트에 실패한 뒤 이전 버전을 사용할 수 없게 되는 문제를 수정했습니다. 예전 내장 읽기 힌트 플러그인을 제거했습니다.
- 화면 항상 켜기와 절전 설정의 행 전체를 눌러 변경할 수 있습니다. 모바일 웹 패널 전환도 개선했습니다.
- 플러그인 목록이 자동으로 새로고침되어도 업데이트 확인 버튼 옆에 마지막 수동 확인 결과가 표시됩니다.
- 시스템 언어와 직접 선택한 언어가 같아도 언어 선택 창을 다시 열면 방금 저장한 항목이 표시됩니다.
- 태블릿에서 설정을 열면 설치 패널이 먼저 표시됩니다. 환경 상태와 버전은 백그라운드에서 읽은 뒤 표시됩니다.
- 실행 환경을 설치하기 전에 제한 모드를 열면 앱이 종료되던 문제를 수정했습니다. 상태 점검 기록이 없는 환경에서도 유지 관리 점검을 계속할 수 있습니다. 구버전에서 옮길 데이터가 없어도 안전 시작이나 빠른 중지 후 일반 시작이 막히던 문제를 수정했습니다. 복구 화면에서 확인된 원인과 세부 정보를 볼 수 있습니다.
- 호환 계층으로 ARM64 앱을 실행하는 Android에서는 유지 관리 디렉터리를 읽거나 진단 기록을 내보낼 때 해당 시스템에 맞는 디렉터리 플래그를 사용합니다.
