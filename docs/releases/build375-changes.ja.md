# DSHA 0.2.2-rc.5-20261122.1650-dsh0.2.2-rc.5 / build375

- アプリと同梱の DSH はともに 0.2.2-rc.5 です。Android 11 以降の arm64 端末では、従来の E7E3 署名で `dsh.android.client` を更新できます。
- ワークスペースの設定を編集するか、選択した設定を復元すると、実際に変更した項目だけが保存されます。ほかの設定は元の値や継承状態を保ちます。サブエージェントのモデルプールで有効・無効の切り替えかモデル一覧の編集だけを行った場合は、変更した項目だけが保存され、もう一方が既定値を継承していれば引き続き既定値の変更が反映されます。カスタムプロバイダーの再試行設定で回数だけを指定した場合、表示名だけを変更しても、再試行モードは引き続き既定値に従います。
- バックグラウンドから戻った後や更新後に前のワークスペースの実行状態を再確認し、終了済みのインスタンスが起動を妨げないようにします。更新後、古いコピーの整理中にホーム画面を開いた場合は、準備が整い次第、自動で実行環境の更新に進みます。これにより、環境チェックの失敗が誤って表示されるのを防ぎます。
- 起動ログに起動時間の計測が終わった位置を表示します。Web ワークスペースの準備後に記録したログには稼働時間を表示し、起動時間とは別に扱います。
- 起動先を Web ワークスペースに設定していると、アプリのホームがバックグラウンドに残っているときに端末のホームからアイコンをタップしても、ワークスペースが開きます。環境のメンテナンスや前のワークスペースの確認が必要な場合は、アプリのホームにとどまります。
- 複製アプリからファイルを別の場所に保存すると、書き込みが完了してから成功と表示されます。ワイヤレスデバッグのペア設定画面で ADB をオフにすると、デバイスの実行チャネルに戻ったときにスイッチがオフと表示されます。 バックグラウンドでの ADB 接続確認が完了、タイムアウト、または中断した場合、その確認用のプロセスだけを終了します。現在のワイヤレスペアリングは保持されます。
- 仮想画面のプリセットに、説明と選択肢が一緒に表示されます。キャンセルすると現在の選択が保持されます。 仮想画面のノードを開いたときに DSHA のアクセシビリティサービスが接続されていなければ、サービスを利用できないことが表示されます。
- モデル設定でプロバイダーを削除すると、現在のプロファイルからその設定が削除され、共有 API キーは保持されます。両方を削除する場合は、先にそのプロバイダーの編集画面でキーを消去して保存し、そのあとでプロバイダーを削除します。設定変更が拒否された場合はキーが保持されます。
- アプリと同期する言語を切り替えると、現在の Web ワークスペースの表示がその場で更新されます。ワークスペースを開いたままライトテーマとダークテーマを切り替えてから戻ると、元のページが表示されます。デスクトップ表示の設定は、新しい Web ビューを作成したときに適用されます。開いている障害レポートの本文とボタンも切り替わります。「原因と修復を表示」から復旧画面を開き、戻るとアプリのホームに戻れます。
- 設定のみのバックアップには、移行可能なアプリの設定、モデル設定、プロファイル、プリセットを含めます。プラグインのインストールパッケージや重複するアーカイブは対象外です。対応する旧設定と、ユーザーが記述したプロファイル設定は保持されます。アプリの API キー項目は専用のオプションで選べます。アプリ全体のバックアップや以前の保管アーカイブは、それぞれの復元手順を使えます。
- ストレージ統計は、一部しか読み取れない分類を示し、読み取れた容量を表示します。読み取れなかった容量は不明となり、空であることを確認した分類は 0 B と表示されます。
- スキルの詳細には最初にプレビューが表示され、ソース全体を開くとページごとに読めます。「最近削除した項目」への移動や復元中も詳細画面が表示され、処理が終わると操作を再開できます。
