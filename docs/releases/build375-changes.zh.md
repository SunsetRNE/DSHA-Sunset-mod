# DSHA 0.2.2-rc.5-20261122.1650-dsh0.2.2-rc.5 / build375

- 应用与内置 DSH 均为 0.2.2-rc.5。Android 11 及以上的 arm64 设备可用原 E7E3 签名覆盖升级 `dsh.android.client`。
- 修改或恢复选定的工作台设置时，只保存实际改动的项目。其他设置保留原值或继承状态。在子代理模型池中，单独切换开关或编辑模型列表时只保存改动的一项，另一项若原来跟随默认值，就会继续随默认值更新。自定义供应商的重试设置只配置了次数时，单独修改显示名称，重试模式仍会跟随默认值。
- 从后台恢复或更新后，重新核对原工作台实例，避免已经退出的实例挡住启动。更新后打开主页时，若后台正在清理旧副本，应用会稍候，等可以继续时自动更新运行时，避免误报「环境检查未通过」。
- 启动日志显示启动计时截止的位置。网页就绪后的日志标明运行时间，不再计入启动阶段。
- 将启动位置设为网页工作台后，从桌面点开仍在后台的原生主页，也会按这个选择进入工作台。需要维护环境或确认上一个工作台时，会留在原生页面处理。
- 双开中的文件另存会等写完再提示成功。从无线调试配对页关闭 ADB 后，返回设备执行通道页时，开关会显示关闭。后台 ADB 连接检查完成、超时或中断后，应用会回收这次检查的进程，保留已有无线配对。
- 虚拟屏规格同时显示说明和可选档位。取消会保留原有选项。打开虚拟屏节点时，如果 DSHA 无障碍服务尚未连接，界面会提示服务不可用。
- 在模型设置中删除供应商，会移除当前档案的供应商配置并保留共用的 API 密钥。如果还要清除密钥，请先在该供应商的编辑页清除并保存，再删除供应商。配置修改被拒时会保留原密钥。
- 在工作台切换与应用同步的语言时，界面会就地更新，保留当前工作台。工作台已打开时，切换浅色或深色主题后返回，会继续显示原网页。桌面布局设置在新建网页视图时生效。已经打开的故障说明也会更新正文和按钮。「查看原因与修复」会打开修复页，返回后再回到原生主页。
- 「仅设置」收集可迁移的原生设置、模型配置、工作档案和预设，以前误带入的插件安装包和重复压缩档已移出此范围。受支持的旧配置和用户写入档案声明的设置会保留。是否纳入原生 API Key 字段由单独选项决定。完整应用备份和旧保留档仍使用各自的恢复入口。
- 存储统计会标明哪些类别没有读全，显示已读到的大小。尚未读到的类别会显示未知，确认空的类别显示 0 B。
- 技能详情先显示预览，打开完整源码后可逐页阅读。移动到最近删除或恢复期间，详情保持可见，任务完成后可继续操作。
