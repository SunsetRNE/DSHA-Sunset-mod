# DSHA 0.2.2-rc.5-20261119.1852-dsh0.2.2-rc.5 / build373

- 应用与内置 DSH 均为 0.2.2-rc.5。Android 11 及以上的 arm64 设备可用原 E7E3 签名覆盖升级 `dsh.android.client`。
- 存储统计和清理会显示进度条、当前阶段和已处理数量。扫描期间可以看到数字持续更新。
- 在“存储与文件”中展开运行时回退副本，可查看各份副本的占用和保留原因。
- 打开主页的插件页时可以先查看已知列表。点击“检测插件”会重新检查，并显示核验状态。
- 手动清理可压缩事务记录和文件内容均通过核对的较旧 DSH 副本。可在明细中把它展开回原位置，原有运行时回退资格保持不变。
