# DSHA 0.2.1-rc.5-20261104.1412-dsh0.2.1-rc.5 / build308

- При подтверждении операции с внешним устройством фиксируется выбранная цель. Ещё не отправленные команды отклоняются, если запрос утратил силу, привязка устройства изменилась или доступ к внешним устройствам отключён.
- Для диагностических команд внешнего устройства проверяются аргументы. wm разрешает только запрос размера и плотности экрана, а logcat принимает поддерживаемые параметры чтения и фильтры. Аргументы для изменения параметров экрана, очистки журнала, изменения размера буфера или записи в файл отклоняются.
