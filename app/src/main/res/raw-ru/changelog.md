- Обслуживающий релиз инженерной сборки (G0): после build359 в `main` вошли только подготовка идентичности публикации Rebirth, документы линии модуляризации и варианты CI — **изменений исходников / ресурсов / текстов приложения нет**. Видимое поведение build360 полностью совпадает с build359; обновление меняет только идентичность сборки и релизную инженерию.
- Подготовка изолированной экспериментальной линии Rebirth: отдельный файл идентичности `dsh.android.client.rebirth`, переключатель неподписанного кандидата `-Pdsha.rebirthCandidate=true`, отдельный `signingConfigs.rebirth` (читает только `DSHA_REBIRTH_*`, не откатывается к производственному ключу) и верификатор кандидата. Первый кандидат (CI run 43188205334) прошёл все 12 проверок идентичности / манифеста / отсутствия подписи.
