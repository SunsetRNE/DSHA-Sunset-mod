# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- Первый запуск переработан в четыре шага (приветствие → назначение → разрешения → готово) вместо трёх страниц ViewPager2 и отдельной страницы подготовки. При `welcomed == false` по-прежнему открывается только знакомство; Main и восстановление запуска проверяют тот же контракт.
- Первое развёртывание теперь выполняется как фоновая задача обслуживания уровня приложения, а прогресс показывается капсулой развёртывания на экране знакомства и в верхней панели Main, без полноэкранного ожидания. Во время развёртывания экран остаётся включённым; экран готовности и один запуск Web появляются только после успеха.
- Обновление поверх теперь открывает ограниченный Main с капсулой в верхней панели, а не полноэкранный `ExtractActivity`. Незавершённая транзакция обслуживания на диске по-прежнему принудительно открывает страницу обслуживания; ограниченный вход не записывает признак готовности, а терминал, Web и плагины проходят проверки среды.
- Добавлены карточки разрешений для семи возможностей устройства и ADB с рекомендацией по назначению и возможностью пропуска. Разрешение на уведомления запрашивается по нажатию в Android 13+; оптимизация батареи только читается, исключение не запрашивается; менеджер Stellar (`roro.stellar.manager`) распознаётся и открывается; текст настроек доступности приведён к реальному имени в системном списке.
- На планшетах от 600dp две колонки, в горизонтальной ориентации телефона шапка и подвал сжимаются, содержимое прокручивается при шрифте 1.3×. versionCode повышен до 218; ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5; в этом раунде установка поверх на реальном устройстве не проверялась, а объём сборки и приёмки определяется этим CI run и квитанцией Release.
