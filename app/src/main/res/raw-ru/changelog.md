# DSHA 0.2.1-rc.5-20261113.1700-dsh0.2.2-rc.1 / build363

- Сборка исправления и инженерных обходных путей (одно видимое исправление, остальное — выключенные по умолчанию инженерные обходные пути и документация): после build362 сборка build363 включает исправление одиночного экземпляра шестерёнки настроек в боковой панели, обходной путь Rust digest R1 и двойную реализацию `verify_plan` PlanView v1 R2, а также базовую линию защиты данных A3 v0.3, оценки управления плагинами / прав производителей / возврата кэша и документ приёмки build362 на устройстве. **Видимое поведение меняет только исправление шестерёнки**; R1 / R2 выключены по умолчанию, не подключены к производственным точкам вызова и не поставляют `.so`; остальное — документация.
- Одиночный экземпляр шестерёнки настроек в боковой панели (видимо пользователю, `DSHA_GEAR_SINGLETON_V1`): перед монтированием в `ensure()` шестерёнка настроек в footer боковой панели `dsh-web-mobile` удаляет оставшиеся в том же `triggerRow` чужие `quick-settings-wrap` и оставляет только свой экземпляр, поэтому после восстановления проекта / горячей перезагрузки / повторной регистрации во время выполнения на странице остаётся не более одной шестерёнки (на устройстве однажды было 3). Защита трогает только собственные узлы плагина, не элементы хоста и не меняет уступку по ширине `DSHA_GEAR_FIT_V1`. **Известная граница**: когда два экземпляра активны одновременно, дедупликация снимает узлы друг друга, и последний вызов `ensure()` перехватывает управление; это конкурентное окно — follow-up и в этой сборке не устранено.
- Обходной путь Rust digest R1 (инженерия, по умолчанию выключен, не входит в пакет): добавлены `util/RustNative` / `RustDigest` / `RustBackends` с JNI-входом только для чтения `digest(fdRange, algorithm)`, откатом на JVM и хост-дифференциальными проверками (SHA-256 / SHA-1, offset/limit/короткое чтение/разбиение на блоки); переключатель уровня выполнения по умолчанию `false` (внутрипроцессный boolean, не подключён к `ConfigStore`, новых ключей конфигурации нет), при сбое возврат на JVM с типизированной причиной. **Не подключён ни к одной производственной точке вызова** (`backup/` не изменён); Rust `.so` остаётся только доказательством CI и не упаковывается в APK. В CI добавлены `rust-differential` (хост `.so` + реальная сверка на JDK 17), `--expect-lock` блокировки артефактов `_node-rust` и подключение `rust_host` для полных модульных тестов.
- Двойная реализация `verify_plan` PlanView v1 R2 (инженерия, по умолчанию выключена, нулевое обслуживание, нет производственной точки вызова): добавлены `util/PlanViewCodec` / `PlanViewValidator` (чистый Java, без Android-импортов) и Rust `rust/crates/dsha-core/src/plan.rs`, замораживающие поля / перечисления / коды причин и порядок нескольких причин проекции плана восстановления v1; JVM и Rust возвращают один и тот же `VALID/INVALID` и набор причин, а **расхождение обрабатывается fail-closed без отката**; также добавлены матрица правил T1–T32 по A3 §5.2 (T30/T32 ждут нативного буфера / слоя подключения A3), генератор фиксированных фикстур, межреализационная фиксация байтов и хост-jvm дифференциал. Переключатель по умолчанию выключен (`RustBackends.planSelection()`), ни `util/`, ни `rust/` не входят в `launcherInputs`, поэтому **сам R2 не добавляет страницы обслуживания**; рецензия не-реализатора — APPROVE, осталось 2 неблокирующих P2: сквозная негативная инъекция и невыполненный путь full `rust_host`.
- Проектные документы и документ приёмки (только документы): базовая линия защиты данных A3 v0.3 (контракт плана восстановления v1 заморожен, Lead вынес решения Q1–Q5, R2 разблокирован и реализован; основная линия A3 ещё не начата) и оценка управления плагинами (согласование семантики bundle/entry, буфер состояния на стороне оболочки, пять пробелов P1 и срезы P0–P4) внесены в индекс документации; оценки прав производителей (AOSP + пять производителей, базовая линия dev-only скрытых API) и автоматического возврата кэша заархивированы; документ приёмки build362 на устройстве (OnePlus 12, 361→362 с одним проходом обслуживания, READY, без сбоев) сохранён.
