# DSHA 0.2.1-rc.3-20261026.0644-dsh0.2.1-rc.3 / build198

- バージョンコードを 198 に更新しました。ターミナルのフローティングボールとワークベンチの「メニュー」はセッションサイドバーを開くようになりました。極簡モードと狭いワークベンチではドロワー、840dp 以上のワークベンチではサイドバーを常時表示します。サイドバーには新規作成、切り替え、名前変更、終了確認、ホーム、表示設定、キーボード、貼り付け、入力フォーカス、説明をまとめています。
- Sunset 独立テストビルドは dsh.android.client.SunsetRNE2 を使用し、正式版 dsh.android.client および以前の SunsetRNE テストビルドと共存できます。
- 本ビルドは Android ビルド、単体テスト、Lint、APK 作成、端末へのインストール・実機検証をまだ行っていません。
