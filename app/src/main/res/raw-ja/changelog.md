# DSHA 0.2.1-rc.5-20261114.1717-dsh0.2.2-rc.1 / build366

- A6 プラグインの識別と状態：インストールパッケージ bundle、profile の選択、entryId/moduleHash/親グループ、明示的な無効化の意図、実際の稼働を区別し、ライフサイクルの phase は pending/loading/unloading/active/failed/null を区別します。内容の証明の欠落、期限切れ、世代変更、識別不一致は引き続き検証待ちです。事前チェック、ブラウザーの ready、履歴を Loader の成功とは扱わず、原因を特定できない起動失敗でその回のプラグイン全体を無効にしません。
- A6 操作結果とカード：一覧、コンパクトカード、詳細では、待機中、キャンセル、タイムアウト、失敗、結果の検証待ちを優先表示し、コミット済みでもカタログが古い状態は別に表示します。互換性は engines.dsh を優先し、なければすべての DSH peer を確認します。既知の非互換、未対応プラットフォーム、確認失敗はコミットを拒否し、厳密なバージョンの例外許可は読み取り専用です。保存済みでもホット適用されていなければ restart-required と表示し、有効化には再起動が必要です。新しい状態と理由の文言は十言語に対応します。
- A6 不明な結果の境界：プラグイン変更処理の終了を検証できない場合は環境の占有を維持し、アプリを再起動してランタイムメンテナンス画面で確認するよう案内します。候補と未完了トランザクションは自動再実行せず、再起動も成功を意味しません。信頼できる A5 の終了証明とデプロイ内容の証明はまだ接続が完了しておらず、保守的な unknown は確認操作や状態文言では解除しません。読み取り専用クエリの結果が不明な場合は、カタログを古い状態にして共有リースを返すだけで、環境を恒久的に占有しません。package.json のない実在ディレクトリを利用可能なプラグインとは表示しなくなります。ユーザーによる無効化、セーフモード、システム／ユーザープラグインの分離は維持します。
- A7 デバイス認可とチャネルの事実：認可スナップショット、世代、実行前の再確認をデバイス認可フェンスに集約し、ユーザーのスイッチ、認可要求、接続、実際のチャネル機能は別々に表示・判断します。Shizuku コールバックと Root 経路は現在の識別情報と明示的なポリシーで再確認し、取り消し、世代変更、利用不能時に過去の成功を根拠に許可しません。システム権限や任意コマンドの入口は追加しません。
- A7 物理画面と仮想画面：物理画面の意味ノード、スクリーンショット座標、入力、ナビゲーションキーは、それぞれ対応する操作証拠を使用します。仮想画面の座標、ノード、editor、anchor、キーという五種類の証拠は、それぞれ Core、世代、対象に束縛します。証拠を黙って交換したり別画面で代替したりせず、UNKNOWN は再実行しません。操作後には新しい観測が引き続き必要です。パスワードテキストの強制ブロックと機微な画面の確認／引き継ぎポリシーは維持します。
- A7 Root モジュールの読み取り専用一覧：デバイス画面に明示的な読み取り入口を追加し、固定の /data/adb/modules にある上限付きのモジュール情報のみを表示します。固定 FD のプローブは、確認済み Magisk/KernelSU/APatch サンプルに従って UID0、現在のインストール識別情報、ファイル識別情報を確認してから、開いたオブジェクトを実行します。不明なバージョンや曖昧な場合は拒否し、PATH を検索せず、Shizuku/ADB へ切り替えません。一覧はスクリプトを読まず、再帰せず、インストール／開始・停止／更新／アンインストールを提供しません。失敗や partial を完全な空一覧とは扱わず、一時停止や認可変更時は古い結果を破棄します。新規文言 14 件は十言語に対応します。ソースのサンプルは管理アプリや実機の互換性認証を意味しません。
- A2 ファイルワークベンチ：設定内のアプリ間ファイルアクセス画面に、既定で無効なファイルワークベンチ（インポートとエクスポート）のスイッチを追加し、成果物ファイル画面では認可、参照、記録の入口を再利用します。転送前と公開前に認可／epoch、読み書きビット、ローカルファイル識別情報を再確認します。途中の取り消し、キャンセル、タイムアウトでは型付きの結果を保持し、自動再実行しません。記録には上限があり、URI、完全なパス、本文を保存しません。Provider は引き続き信頼境界で、外部ファイルのその場での上書きに失敗すると不完全なファイルが残る可能性があり、内容レベルでの認証情報のコピー防止は保証しません。
