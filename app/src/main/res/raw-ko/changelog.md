# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- 첫 실행 안내를 4단계(환영 → 용도 → 권한 → 완료)로 재구성하고 기존 3페이지 ViewPager2와 별도 준비 페이지를 대체했습니다. `welcomed == false`이면 여전히 안내만 열리며 Main과 시작 복구 화면은 같은 계약을 계속 검증합니다.
- 첫 배포는 앱 수준 백그라운드 유지보수 작업으로 실행되고, 진행 상황은 안내 화면과 Main 상단 바의 배포 캡슐에 표시됩니다. 전체 화면으로 기다리지 않으며 배포 중에는 화면을 켜 두고, 성공한 뒤에만 완료 화면과 Web 1회 시작으로 넘어갑니다.
- 덮어쓰기 업데이트는 전체 화면 `ExtractActivity`로 이동하지 않고 제한된 Main과 상단 바 캡슐로 진행됩니다. 디스크에 미완료 유지보수 트랜잭션이 있으면 기존처럼 유지보수 페이지로 강제 이동하며, 제한 진입은 준비 완료 표시를 쓰지 않고 터미널·Web·플러그인 실행은 환경 게이트를 통과해야 합니다.
- 권한 카드(7가지 기기 기능 + ADB, 용도별 추천과 건너뛰기 가능)를 추가했습니다. 알림 권한은 Android 13+에서 탭 시 요청하고, 배터리 최적화는 읽기 전용으로 확인하며 예외를 요청하지 않습니다. Stellar 관리자(`roro.stellar.manager`)를 인식해 열 수 있고, 접근성 설정 문구는 실제 시스템 목록 이름으로 통일했습니다.
- 태블릿 600dp 이상은 2열, 휴대폰 가로 화면은 머리말과 바닥글을 압축하며 본문은 1.3배 글꼴에서도 스크롤됩니다. versionCode는 218로, DSHA 개정은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다. 이번 라운드는 실제 기기 덮어쓰기 설치 검증을 하지 않았고 빌드·수용 범위는 이번 CI run과 Release 영수증을 따릅니다.
