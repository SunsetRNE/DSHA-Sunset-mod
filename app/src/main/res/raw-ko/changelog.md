# DSHA 0.2.1-rc.5-20261114.1717-dsh0.2.2-rc.1 / build366

- 플러그인 관리, 기기 기능, 파일 워크벤치 통합 빌드: build366은 릴리스된 build365 이후 A6 플러그인 관리 P0–P4, A7 기기 기능 및 화면 인식 S1–S5, A2 파일 워크벤치 slice3/4, A5 S1 페이지 환경 샘플링 정리를 통합합니다. A8 첫 단계는 작업 기준선만 동결하며, A3 slice4와 A5의 후속 동작 슬라이스는 아직 제공되지 않았습니다.
- A6 플러그인 식별 및 상태: 설치 패키지 bundle, profile 선택, entryId/moduleHash/상위 그룹, 명시적 비활성화 의도, 실제 실행을 구분하며, 수명 주기 phase는 pending/loading/unloading/active/failed/null을 구분합니다. 콘텐츠 증거 누락, 만료, 세대 변경, 식별 불일치는 계속 검증 대기 상태입니다. 사전 점검, 브라우저 ready, 과거 기록을 Loader 성공으로 취급하지 않으며, 원인을 특정할 수 없는 시작 실패로 해당 회차의 모든 플러그인을 비활성화하지 않습니다.
- A6 작업 결과 및 카드: 목록, 간결한 카드, 상세 화면은 대기열, 취소, 시간 초과, 실패, 결과 검증 대기를 우선 표시하고, 커밋되었지만 카탈로그가 오래된 경우는 별도로 표시합니다. 호환성은 engines.dsh를 우선하고 없으면 모든 DSH peer를 검사하며, 알려진 비호환, 미지원 플랫폼, 검사 실패 시 커밋을 거부합니다. 정확한 버전별 예외 허용은 읽기 전용입니다. 저장되었지만 핫 적용되지 않은 경우 restart-required를 표시하며, 적용하려면 여전히 재시작이 필요합니다. 새 상태와 사유 문구는 10개 언어를 지원합니다.
- A6 알 수 없는 결과의 경계: 플러그인 변경 작업의 종료를 검증할 수 없으면 환경 점유를 유지하고, 앱을 재시작한 뒤 런타임 유지보수 페이지에서 확인하도록 안내합니다. 후보와 미완료 트랜잭션을 자동 재실행하지 않으며, 재시작은 성공을 의미하지 않습니다. 신뢰할 수 있는 A5 종료 증거와 배포 콘텐츠 증거는 아직 연결이 완료되지 않았으며, 보수적인 unknown은 확인이나 상태 문구로 해제되지 않습니다. 읽기 전용 조회의 결과가 불명확하면 카탈로그를 오래된 상태로 표시하고 공유 임대를 반환할 뿐 환경을 영구 점유하지 않습니다. package.json이 없는 실제 디렉터리는 더 이상 사용 가능한 플러그인으로 표시하지 않습니다. 사용자의 비활성화, 안전 모드, 시스템/사용자 플러그인 계층 분리는 유지합니다.
- A7 기기 권한 및 채널의 실제 상태: 권한 스냅샷, 세대, 실행 전 재검증을 기기 권한 펜스로 통합하며, 사용자 스위치, 권한 요청, 연결, 실제 채널 기능은 따로 표시하고 판단합니다. Shizuku 콜백과 Root 경로는 현재 식별 정보와 명시적 정책에 따라 재검증하며, 철회, 세대 변경, 사용 불가 시 과거 성공을 근거로 허용하지 않습니다. 시스템 권한이나 임의 명령 진입점을 추가하지 않습니다.
- A7 물리 화면 및 가상 화면: 물리 화면의 의미 노드, 스크린샷 좌표, 입력, 탐색 키는 각각 해당 동작 증거를 사용합니다. 가상 화면의 좌표, 노드, editor, anchor, 키라는 다섯 종류의 증거는 각각 Core, 세대, 대상에 바인딩합니다. 증거를 조용히 교환하거나 다른 화면으로 대체하지 않고 UNKNOWN을 재실행하지 않으며, 동작 후에는 여전히 새 관측이 필요합니다. 비밀번호 텍스트 강제 차단과 민감 화면 확인/인계 정책은 유지합니다.
- A7 Root 모듈 읽기 전용 목록: 기기 페이지에 명시적 읽기 진입점을 추가하고, 고정된 /data/adb/modules의 제한된 모듈 정보만 표시합니다. 고정 FD 탐색은 검토한 Magisk/KernelSU/APatch 샘플을 기준으로 UID0, 현재 설치 식별 정보, 파일 식별 정보를 확인한 뒤 이미 연 객체를 실행합니다. 알 수 없는 버전이나 모호한 경우에는 거부하며, PATH를 검색하거나 Shizuku/ADB로 전환하지 않습니다. 목록은 스크립트를 읽거나 재귀 탐색하지 않으며, 설치/시작·중지/업데이트/제거 기능을 제공하지 않습니다. 실패와 partial을 완전한 빈 목록으로 취급하지 않고, 일시 중지나 권한 변경 시 이전 결과를 폐기합니다. 새 문구 14개는 10개 언어를 지원합니다. 소스 샘플은 관리 도구나 실기기 호환성 인증을 의미하지 않습니다.
- A2 파일 워크벤치: 설정의 앱 간 파일 접근 페이지에 기본적으로 꺼진 파일 워크벤치(가져오기 및 내보내기) 스위치를 추가하고, 결과물 파일 페이지에서는 권한, 탐색, 기록 진입점을 재사용합니다. 전송 전과 게시 전에 권한/epoch, 읽기·쓰기 비트, 로컬 파일 식별 정보를 재검증합니다. 도중에 권한이 철회되거나 취소 또는 시간 초과가 발생하면 유형이 지정된 결과를 보존하고 자동 재실행하지 않습니다. 기록은 제한되며 URI, 전체 경로, 본문을 저장하지 않습니다. Provider는 여전히 신뢰 경계이며, 외부 파일을 제자리에서 덮어쓰다 실패하면 불완전한 파일이 남을 수 있고, 콘텐츠 수준에서 자격 증명 복사 방지를 보장하지 않습니다.
- A5 및 엔지니어링 마무리: S1은 페이지의 읽기 전용 환경 샘플링을 정리하고 기존 판단 기준을 유지할 뿐이며, latest/trial 연결을 수정했거나 APK 자동 검사를 중단했다고 주장하지 않습니다. A7 병합 후 CI 컴파일 목록에 동작 증거 클래스를 보완하고, Root 목록 테스트는 실제 JSON을 사용하는 Robolectric 경로로 변경합니다. 이 수정이 이 빌드의 전체 CI나 기기 인수가 완료되었음을 뜻하지는 않습니다.
