- Rust digest 측면 경로 R1(엔지니어링, 기본 꺼짐, 패키지 미포함): `util/RustNative` / `RustDigest` / `RustBackends`를 추가하고 읽기 전용 `digest(fdRange, algorithm)` JNI 진입점, JVM 폴백, 호스트 차분(SHA-256 / SHA-1, offset/limit/짧은 읽기/분할)을 제공합니다. 실행 계층 스위치는 기본 `false`(프로세스 내 불리언, `ConfigStore` 미연결, 새 설정 키 없음)이고 실패는 유형화된 이유로 JVM으로 돌아갑니다. **생산 호출 지점에는 미연결**(`backup/` 불변)이며 Rust `.so`는 여전히 CI 증거 전용으로 APK 패키징에 연결하지 않습니다. CI에는 `rust-differential`(호스트 `.so` + JDK 17 실제 대조), `_node-rust` 산출물 잠금 `--expect-lock`, full 단위 테스트 `rust_host` 연결을 추가합니다.
