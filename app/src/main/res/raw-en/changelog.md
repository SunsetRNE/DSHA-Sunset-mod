# DSHA 0.2.1-rc.5-20261113.1000-dsh0.2.2-rc.1 / build362

- Engineering-infrastructure build (no new user interface): after build361, build362 lands the Kotlin toolchain batch, Rust side-path R0, A2 storage/files slice1+2, plus the A7 / R1 design documents and the build361 device-acceptance receipt. **The Kotlin and Rust batches are build/format/native-side-path infrastructure and do not change user-visible behavior**; A2 is a capability-layer/ledger replacement and adds no user interface.
